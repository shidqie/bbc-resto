## Pembagian Menu Utama

Pada landing page, menu sebaiknya dibagi menjadi tiga bagian utama agar konsumen mudah

Untuk tampilan landing page, kategori menu dine-in dibuat lebih rapi dan mudah dipahami.

| No  | Kategori Menu           | Keterangan                                                                |
| --- | ----------------------- | ------------------------------------------------------------------------- |
| 1   | Paket Nasi Ayam         | Menu paket nasi, liwet, atau nasi TO dengan ayam biasa                    |
| 2   | Paket Nasi Ayam Kampung | Menu paket nasi, liwet, atau nasi TO dengan ayam kampung                  |
| 3   | Paket Nasi Bebek        | Menu paket nasi, liwet, atau nasi TO dengan bebek                         |
| 4   | Lauk Satuan             | Lauk yang dapat dipesan terpisah seperti ayam, bebek, tahu, dan tempe     |
| 5   | Sayur dan Lalapan       | Menu pelengkap seperti karedok, lotek, pete, jengkol, sambal, dan lalapan |
| 6   | Tambahan                | Menu tambahan seperti nasi, liwet, nasi TO, dan sambal                    |
| 7   | Minuman Kopi Susu       | Varian es kopi susu                                                       |
| 8   | Classic Coffee          | Menu kopi klasik seperti americano, cappuccino, cafe latte, dan espresso  |
| 9   | Manual Brew Coffee      | Menu kopi manual brew seperti kopi tubruk, V60, dan vietnam drip          |

## Filter Menu pada Landing Page

Untuk tampilan konsumen, filter menu pada landing page dapat dibuat lebih sederhana.

| No  | Filter            | Keterangan                                           |
| --- | ----------------- | ---------------------------------------------------- |
| 1   | Semua             | Menampilkan semua menu dine-in                       |
| 2   | Paket Nasi        | Menampilkan paket nasi ayam, ayam kampung, dan bebek |
| 3   | Lauk              | Menampilkan lauk satuan                              |
| 4   | Sayur dan Lalapan | Menampilkan menu sayur, lalapan, dan pelengkap       |
| 5   | Tambahan          | Menampilkan menu tambahan                            |
| 6   | Minuman           | Menampilkan seluruh menu minuman                     |
